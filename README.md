# Spotify Artists Data Analysis using Python

## Project Overview

This project analyzes Spotify artist data using Python. The analysis includes data cleaning, exploratory data analysis (EDA), and visualizations to uncover trends in artist popularity, genres, countries, and streaming performance.

---

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## Project Workflow

1. Import Dataset
2. Data Cleaning
3. Handling Missing Values
4. Exploratory Data Analysis
5. Data Visualization
6. Insights

---

## Key Insights

- Most streamed artists
- Genre popularity
- Country-wise artist distribution
- Stream analysis
- Correlation between numerical features
